## 三、尺寸账本（无任务书图纸 → 全部按教材典型值 Designer-choice 拍板）

- 底板 120×60×16，四角 R10，孔 2×⌀16 中心距端 15
- 圆筒外 ⌀50 内 ⌀26，长 60（与底板前后平齐），轴线高 50
- 支承板厚 12（贴圆筒前端面），两侧与 ⌀50 相切
- 肋板厚 10（X55..65），深 36（前后对称），高至圆筒底切线 25
- 交叉验证：圆筒长 60 = 底板深 60（前后平齐）；支承板切点高 = 轴线高 50

## 四、已知简化（如实记录）

1. 粗糙度符号为简化画法（两腿+属性文字），未做完整的 GB/T 131 符号库
2. 主视图未画 A—A 剖切符号与箭头（剖切位置由中心线隐含）
3. 未标注铸造圆角/起模斜度等工艺细节；标题栏为简化格式
4. 左视全剖中，肋板区空白按"纵剖不剖"处理，肋板与圆筒相贯线未做精确求交

## 五、验证结果

- **L2 实体数**：82（10 标注 / 4 圆 / 4 弧 / 2 填充 / 9 虚线 / 7 中心线 / 26 实线 / 9 文字 / 2 块参照 / 图框标题栏）
- **L3 审计**：按 (ObjectName, Layer) 分类型清点全部符合预期；`PurgeAll()` 无残留；图层 WALL/HID/CEN/HAT/DIM/TXT/TB 颜色线型符合 cad-designer 国标配色
- **L4 视觉审查**（PNG 出图后）：发现并修复 3 处——A—A 视图名与 60 尺寸文字重叠、Ra6.3 符号压 120 尺寸线、填充对象误落 WALL 层；修复后复检通过
- 投影关系：主俯长对正、主左高平齐 ✓

## 六、自动化实战发现（已写入 cad-automation skill v1.2.0 第十八章）

1. COM 忙时抛 -2147418111，**属性访问也会被拒** → 重试必须包属性链（lambda）
2. Documents 归零后 COM 集合方法解析失败 → 绝不让文档数归零
3. `_AUDIT _Y` 会追加"写报告?"提示**永久挂起** SendCommand；`_PURGE` 应答错位 → 用 `doc.PurgeAll()` API
4. `AddDimDiametric` 是 3 参；迭代引用传标注 API 易报「对象已被删除」→ 直径尺寸用跨象限 `AddDimAligned` + `%%c` 覆盖
5. 出图：`BACKGROUNDPLOT=0` + `DWG To PDF.pc3`（ISO_A3）+ `PublishToWeb PNG.pc3`（1600×1200）
